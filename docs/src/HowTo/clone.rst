===================================
How to Clone the Git Repository
===================================

Install Git Large File Storage (git-lfs) in your .gitconfig (one-time step per Unix environment)

.. code-block:: bash

  $ git lfs install

Clone the git repo with git-lfs enabled

.. code-block:: bash

  $ git clone --recursive https://github.com/slaclab/Simple-10GbE-RUDP-KCU105-Example.git
